## Важный контекст

Это **не сайт существующего барбершопа**. Sports Cave Barbershop — вымышленный демонстрационный бренд для MVP, который в дальнейшем планируется предлагать реальным барбершопам как продукт. Контактные данные (телефон, адрес) намеренно выглядят как плейсхолдеры, а не выдаются за настоящие. Мультитенантность/шаблонизация под разных клиентов сейчас не проектируется — см. [business-requirements.md](./business-requirements.md).

## Технологический стек

- **Framework**: Next.js 16 (App Router), TypeScript, React 19
- **Стили**: Tailwind CSS 4, дизайн-система "Gridiron & Groom" (см. [design-system.md](./design-system.md))
- **БД**: Vercel Postgres (Neon) + Drizzle ORM — для брони, с уникальным ограничением (мастер+дата+время)
- **Уведомления**: Telegram Bot API (секреты пока не заполнены)
- **Деплой**: Vercel (проект ещё не создан/не связан)
- **Package manager**: npm

Полное обоснование — [architecture.md](./architecture.md).
